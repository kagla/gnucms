# 알림톡 운영 모듈

`plugins/bizppurio`를 필수로 사용하는 전체 관리자 전용 운영 화면이다.
템플릿·발송·이력 데이터는 플러그인이 소유하고 모듈은 공개 서비스 계약으로 접근한다.
실제 업무 이벤트의 자동 발송, 예약 저장, 문자 대체, KAPI 검수 신청은 포함하지 않는다.

## 실행 순서

1. [비즈뿌리오 플러그인](../../plugins/bizppurio/README.md)을 켜고 데이터를 설치한다.
2. 플러그인 설정에서 계정·발신프로필·테스트 번호를 저장하고 결과 URL을 업체에 등록한다.
3. **모듈 → 알림톡 운영**을 켜고 저장한 뒤 실행 주소 링크나 옆의 새 창 아이콘을 누른다.
4. 사용할 검수/운영 환경에서 **템플릿**을 열어 승인된 기본 텍스트 본문과 WL 버튼을 등록한다.
5. 플러그인 설정에서 해당 환경의 발송을 허용한다.
6. **웹발송**에서 계정 유형·인증 상태·테스트 번호 제한을 확인하고 템플릿과 번호·변수를 입력해 미리본다.
7. 최종 내용을 확인하고 **확인한 번호로 알림톡 발송**을 누른다.
8. 상세 화면에서 업체 접수와 카카오 도달 결과를 각각 확인한다.

실행 주소는 `/modules/alimtalk/home`이다. 하위 디렉터리 설치를 지원한다.
일반 회원과 비회원은 접근할 수 없으며 변경 요청은 기존 CSRF 검사를 통과해야 한다.
업무별 본문은 패키지에 두고 관리자 공통 레이아웃·글꼴·폼·버튼·표·다크 모드를 사용한다. 테마의 `extensions/alimtalk/`에서 화면과 개별 조각을 재정의할 수 있다.

## 화면과 동작

- **템플릿:** 로컬 이름·승인 코드·고정 본문·버튼·사용 여부 설정. `#{이름}` 변수를 정의한다.
  버튼의 URL 변수는 경로/쿼리 값으로 인코딩하며 도메인을 변수로 바꿀 수 없다.
- **웹발송:** 10분간 유효한 미리보기 확인값을 서버 세션에 저장한다. 실제 발송 POST는 이
  확인값으로만 진행하며 브라우저가 바꾼 숨은 본문을 신뢰하지 않는다. 설정이나 템플릿이
  바뀌면 다시 미리보기를 요구한다. 한 세션에서 최근 미리보기 10개까지 유지한다.
- **이력:** 환경·기간·접수 상태 검색과 20건 단위 페이지. 전체 전화번호를 표시하지 않는다.
- **상세:** 발송 당시 본문, 요청 식별자, 접수 시도와 도달 결과·실패 사유를 표시한다.
- **결과 재요청:** 기존 메시지의 웹훅을 재요청한다. 바로 도달 성공으로 바뀌지는 않는다.
- **재시도:** 인증/호출 제한으로 명확하게 거절된 요청에 한해 서비스가 가능 여부를 검사한다.
  접수 불명확한 요청을 다시 보내지 않는다.
- **보관 만료 개인정보 정리:** 90일이 지난 발송에서 수신정보·본문을 최대 100건씩 지운다.
  기본 보관 기간은 현재 고정이며 자동 정리·보관 기간 설정 UI는 제공하지 않는다.

등록된 템플릿은 원격 미확인 상태다. 승인 여부·본문·버튼 구성을 비즈뿌리오에서 확인해야 한다.
미리보기는 카카오 앱의 실제 말풍선 모양을 보장하지 않는다. 검수 환경도 계정 조건에 따라
실제 수신·과금이 발생할 수 있으므로 테스트 번호를 사용한다.

모듈 OFF는 운영 화면을 중단하지만 플러그인이 켜져 있으면 다른 모듈의 발송과 웹훅 수신은
유지된다. 전체 발송을 멈추려면 플러그인 설정의 **신규 발송 정지**를 사용한다.
비활성 관리자 테스트는 제공하지 않는다.

모듈은 `status.v1` 서비스로 발송 계정 상태를 읽는다. 웹발송 계정의 API 인증 전에는
발송 허용을 켤 수 없으며, 발송 정지 상태에서는 최종 발송 버튼을 비활성화한다.
서버도 같은 조건을 검사하므로 브라우저에서 버튼을 조작해도 발송하지 않는다.
미리보기는 발송 정지 중에도 사용할 수 있다.

**비즈뿌리오 사이트에서 웹발송**은 공식 사이트를 여는 별도 진입 경로다. 사이트에 직접
로그인한 뒤 발송하며 그 내역은 GNUCMS 이력에 자동 등록하지 않는다. 웹발송 계정의
GNUCMS 내 발송은 REST API 사용이 허용된 경우에 가능하고, 별도 웹발송 전용 API 연동은
공개 규격을 확인하지 못해 제공하지 않는다. [계정 유형 안내](../../plugins/bizppurio/README.md)를 참고한다.
