# 작은 쇼핑몰

상품 옵션 두 종류와 조합별 판매가·원가·재고, 회원 주문·배송, 취소·반품·환불·교환, 수량·금액 정산을 제공하는 1인 운영 모듈이다.

관리: `/admin/shop` · 사용자 상점: `/shop`

사용자 기본 주소는 `extension.json`의 `route_prefix`, 관리자 주소는 `admin_route_prefix`로 지정한다. 상품 목록(`/admin/shop/products`)과 등록(`/admin/shop/products/new`)·수정 화면을 분리하며, 등록 시부터 옵션 조합별 최종 판매가와 재고를 입력한다. 기존 관리 화면의 GET은 새 주소로 이동한다. 이전 `/modules/shop/...` 주소도 동일한 권한·CSRF·콜백 인증을 거쳐 계속 처리한다. 패키지 ID와 폴더는 `modules/shop`을 유지한다.

상품 등록·수정에서 최대 20장의 이미지를 선택하고 미리보기의 드래그·터치·이동 버튼으로 순서를 조정한다. 상품 저장 한 번으로 기본 정보·옵션·이미지·순서를 함께 저장하며, 실패하면 이번 변경 전체를 취소한다. 첫 이미지는 대표 이미지가 되며 상품 상세에서 순서대로 확인한다. 기존 설치는 쇼핑몰 운영 화면에서 데이터 설치/갱신을 실행하면 기존 대표 이미지를 보존한 채 갤러리를 사용할 수 있다.

원가는 빈칸(미입력)과 0원을 구분하며 주문 당시 금액을 보존한다. 정산 화면에서 결제 기간별 상품 실매출·소진 원가·이익·이익률을 확인한다. 취소·반품·교환을 반영하고 미입력 원가와 연결되지 않은 부분 환불은 계산 보류로 표시한다. 기존 설치는 데이터 설치/갱신으로 4판 원가 컬럼을 추가하며 과거 원가를 임의로 채우지 않는다.

상품 설명은 기존 CKEditor로 서식과 본문 사진을 편집한다. 설명은 비워 둘 수 있으며, 저장할 때 HTML을 정화하고 사용자 상세 화면에 서식을 표시한다. 옵션 조합 적용과 저장 오류에서도 작성 중인 설명과 사진을 유지한다.

활성화하면 사이트 상단·모바일 메뉴에 사용자 상점을 연결한다. 상품 검색·옵션 선택·장바구니·주문서·결제·내 주문·취소·반품·교환을 사이트 공통 테마와 다크 모드에서 사용한다. 비회원 장바구니는 로그인 뒤 유지되고 주문서로 돌아오며, 회원정보 수정에서도 내 주문을 열 수 있다.

결제는 PG 상점 코드로 직접 연동한다. 현재 이니시스·토스페이먼츠 어댑터를 연결하며 KCP·KSPay는 미확인 규격으로 결제 선택을 차단한 준비 단계다. API 실행 전 관리자에서 각 패키지 데이터를 설치하고 테스트/운영 설정을 저장해야 한다.

[설치·운영·오류 복구·정산 기준](../../docs/shop.md)을 참고한다.
