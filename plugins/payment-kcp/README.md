# NHN KCP 결제 플러그인

LITE PAY 거래 등록·승인과 직접 취소 코드를 작성했다. **거래조회 서명 규격이 미확인되어 미완성 상태이며 쇼핑몰 결제 선택과 관리자 API 실행 허용을 차단한다.** 공개 조회 문서는 서명식에 `mod_type`을 포함하지만 조회 요청 항목/값을 명시하지 않는다. 공식 테스트 인증서를 사용한 조회는 `S032`로 거부되어 검증하지 못했다. KCP의 조회 규격·사용 권한 확인이 필요하다.

- 설정: `/plugins/payment-kcp/settings`
- 서버 계약: `gateway.v2` (`GnuCms\Payment\Gateway`)
- 결제 설정: site_cd, 서비스 인증서 PEM, RSA 개인키 PEM, 개인키 비밀번호
- 리셀러 코드는 가맹점 등록용이다. 결제 요청에는 PG가 발급한 상점 코드를 사용한다.
- 인증 정보와 요청 처리 기록은 암호화한다. 카드번호·인증 토큰·PG 응답 원문은 저장하지 않는다.
- 패키지 스키마 2에서 거래 요청 기록 테이블을 추가한다. 관리자에서 데이터 설치/갱신이 필요하다.
- 복원 후 API 실행은 정지된다. 결제사와 거래를 대조한 뒤 다시 허용한다.
