# 토스페이먼츠 결제 플러그인

상점별 API 개별 연동 키로 토스페이먼츠의 PC·모바일 카드·간편결제창, 서버 승인·조회, 전체·부분 환불을 연결한다.

- 설정: `/plugins/payment-toss/settings`
- 설정 화면은 관리자 공통 레이아웃·글꼴·입력·버튼·환경 탭·다크 모드를 사용한다.
- 서버 계약: `gateway.v2` (`GnuCms\Payment\Gateway`)
- 주문 처리·결제창 표시·결과 수신은 이 계약을 사용하는 별도 모듈에서 구현한다. `main`에는 작은 쇼핑몰 모듈을 포함하지 않는다.
- 같은 상점의 MID, 클라이언트 키(`ck`), 시크릿 키(`sk`)를 등록한다. API 버전은 `2022-11-16`을 사용한다.
- 테스트·운영 키를 분리한다. 주문서형·결제창형 키(`gck/gsk`)는 지원하지 않는다. SDK V2의 `payment().requestPayment()`를 사용한다.
- 리셀러 코드는 가맹점 등록에 사용한다. 결제창·서버 API는 등록된 상점의 연동 키로 인증한다.
- 인증 정보와 거래 처리 기록은 암호화한다. 브라우저에는 공개 클라이언트 키만 전달한다.
- 인증 결과의 주문번호·금액을 검증하고 승인 후 서버 조회로 결제·환불 원장을 확정한다. 승인 응답 유실은 주문번호로 조회한다.
- 환불은 잔액 검사와 멱등키를 사용한다. 불확실한 요청은 재전송하지 않고 관리자 대조로 처리한다.
- 관리자에서 플러그인 데이터를 설치하고 API 실행을 허용한다.
- 실제 가맹점 계정으로 PC·모바일 승인·전체/부분 취소를 검증한 뒤 운영 환경을 사용한다. 자동 테스트는 PG·SDK 응답을 대체한다.
