## 실제 사이트에서 확인한 흐름

- 관리자 분류·상품 등록, 이미지 업로드·썸네일 표시, 상세 설명 저장. 선택옵션 6개·2개 조합의 AJAX 생성과 추가옵션 저장.
- 장바구니에서 본품과 추가 구성을 묶고, 추가 구성을 상품 항목 수에서 제외. 수량·옵션 가격·총액 계산.
- 무통장 주문 접수 → 입금 확인 → 상품 준비 → 배송 중 → 배송 완료. 상태와 처리 이력, 수납액을 DB와 대조.
- 주문 접수 시 티셔츠 화이트/L 20→18, 선물 포장 10→9, 컵 세트 15→14. 입금·배송 단계에서 중복 차감 없음. 배송 완료 시 티셔츠 판매수량 2, 컵 세트 판매수량 1이며 추가 구성은 본품 판매수량에 포함하지 않음.
- 모바일 주문의 상품금액 34,000원 + 배송비 3,000원. 토트백 블랙 20→19, 파우치 10→9.
- 비회원의 잘못된 조회 비밀번호 거부와 올바른 비밀번호 조회. 입금 전 취소와 재취소 요청에서 재고는 한 번만 복원.
- 같은 주문서 재제출 시 기존 주문 반환. 주문 추가 생성이나 추가 재고 차감 없음.
- 입금 확인 전 배송 중으로 건너뛰는 요청 거부.
- 무통장 부분 환불 3,000원과 나머지 5,000원 환불 기록. 같은 환불 키 재전송 시 이중 반영 없음. 전액 환불 후 취소되며 노트 재고가 2개로 복원.
- 관리자 폼에서 선물 포장 재고 9→1로 변경한 후 2개 담기: HTTP 422로 같은 상품 화면에서 안내하고 기존 선택·수량 유지. 장바구니에 본품만 일부 들어가지 않음.
- 주문서 작성 중 같은 추가옵션 재고를 줄인 뒤 최종 주문 제출: HTTP 422로 거부하며 주문 생성·상품 및 옵션 재고의 부분 변경 없음. 검증 후 재고를 9개로 복원.
- 바로 주문하기의 별도 주문서가 기존 장바구니를 유지.
- 1440px·390px 메인·분류·상품 화면의 라이트·다크 모드, 상품 이미지 로딩과 가로 넘침 확인. 모바일 주문 상세의 라이트·다크 모드도 확인.

## 자동 검증

개발 사이트 DB를 사용하지 않고, SQLite와 Docker의 격리된 MySQL 8.4 테스트 DB를 사용했다.

| 실행 범위 | 결과 |
| --- | --- |
| `tests/Shop` | 129개 테스트, 1,812개 assertion 통과 |
| `tests/Payment`, `tests/Web/ShopAdminTest.php`, `tests/Web/ShopCommerceTest.php` | 116개 테스트, 1,748개 assertion 통과 |
| `tests/Browser/ShopAdminOptions.cjs` | 통과: AJAX·입력 보존·아래 복사·마우스/터치 드래그·키보드 정렬·모바일·다크·JS 미사용 |
| `tests/Browser/ShopOptions.cjs` | 통과: 다중 조합·수량·최대 구매수량·재고 변경·실패 입력 보존·모바일·다크 |
| `tests/Browser/ShopCart.cjs` | 통과: 추가 구성 묶음·수량 변경·삭제·저장·반응형·다크·JS 미사용 |

관련 PHP 테스트 합계 **245개, 3,560개 assertion**이다. 이번에는 전체 코어 테스트를 재실행하지 않았다. 결제 테스트의 카드 승인·콜백 검증·타임아웃·조회·환불·중복 방지는 외부 결제사 응답을 대역으로 제공한 결과다.

## 남은 범위와 발견 사항

- 이니시스 테스트·운영 설정이 모두 없어 **실제 PG 결제창 인증·승인·취소·환불은 미검증**이다. 카드번호나 실제 결제 계정을 입력하지 않았다.
- 실시간 계좌이체·가상계좌·간편결제, 쿠폰·적립금, 주문 알림 등 현재 구현 범위 밖 기능을 검증 완료로 표시하지 않는다.
- 브라우저의 네트워크 검사에서 공통 **`/favicon.ico` 404**가 발견됐다. 메인·분류·상품 HTML 및 상품 이미지, 확인한 JS 실행·가로 넘침 검사는 통과했지만 네트워크 검사 전체를 무오류로 표시하지 않는다. 주문 흐름과 무관한 파비콘 경로는 변경하지 않았다.
- 테스트 중 새로운 쇼핑몰 PHP 경고는 관찰되지 않았다. 운영 안내 문서에 남아 있던 예전 결제·상태 전환·환불 설명을 현재 동작에 맞췄다.

## 데이터와 설정 보존

- 시작 전 백업: `gnucms-mysql-20260922-223509.zip`.
- 샘플 재검토용으로 무통장 계좌 안내 **테스트 전용 / 실제 입금 금지 / 샘플 스토어**, 배송비 3,000원·50,000원 이상 무료, 결제 환경 `test`를 남겼다. 실제 은행 계좌는 등록하지 않았다.

- SMTP·알리고 설정은 변경하지 않았고 실제 메일·문자는 보내지 않았다. 임시 비밀번호·쿠키·연결 비밀정보는 저장소에 기록하지 않았다.
- 기존 자체 쇼핑몰의 미커밋 작업을 보존했다. 이번 작업에서 기능 코드를 추가로 바꾸지는 않았다.
