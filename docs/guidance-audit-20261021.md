# 공개 안내 정합성 점검 · 2026-10-21

GNUCMS 코어 GitHub main, 공식 사이트 GitHub feat/modern-theme, gnucms.charmgen.com, gnucms.com 및 별도 원격 설치기의 공개 안내를 대조했다. 54개 기존 매뉴얼의 본문·목록·검색 색인, README와 운영/개발 문서, 홈페이지 문구, 공개 게시글·댓글·문서·소개 설정을 확인했다. 기준은 실제 라우트·설정·서비스 구현과 배포 워크플로다.

## 정리한 차이

- PHP·DB 기준을 유지하고 현재 지원 범위 표를 추가했다.
- 백업 가져오기/검증과 수동 복원을 구분하고, 자동 복원·자동 5개 보관·자동 업그레이드 백업으로 읽히던 안내를 정정했다.
- 신규 KCP REST 결제와 기존 거래 처리를 구분했다. KCP 모듈은 완성 배포 ZIP에 포함되며, 실행 환경 확인과 기존 storage 유지 시 수동 배치가 필요할 수 있음을 명시했다. KCP TCP/IP의 전체 취소·자체 원장 조회 제한을 반영했다.
- 쇼핑몰 공개 설정, 회원 주문, 추가 분류 최대 20개, 반품 범위와 결제 설정 경로를 맞췄다.
- 공통 알림 메뉴, 전화 채널 방식, SMTP 공급자와 알림함 대상 이벤트를 실제 구현에 맞췄다.
- 공식 사이트 modern 테마와 일반 배포 코어의 화면 fallback 차이를 명시했다.
- 개발 계획과 날짜가 있는 검증 기록에는 과거 기록 표시와 현재 지원 문서 링크를 추가했다. 과거 실행 결과와 출시 기록은 보존했다.
- 호스팅 요금 예시의 날짜·VAT·별도 설치비를 공식 상품 안내에 맞췄다.
- 원격 설치기의 폴더 탐색·기존 파일 처리·실제 검증 범위·결제 설정 책임을 바로잡았다. 서비스 내부 작업 저장소의 SQLite와 설치되는 GNUCMS의 MySQL/MariaDB는 구분했다.
- 지원 범위와 충돌하는 공개 토론에는 운영자 명의의 현재 안내를 붙이고 작성자의 원문·작성 시각은 보존했다.

## 확인 범위와 한계

문구·JSON 구조·목록/관련 문서/소스 참조·검색 색인과 변경 전후 내용을 정적으로 검토했다. 기능 테스트, PHP lint, 실제 결제·발송·설치·복원은 실행하지 않았다. 소스가 지원하는 기능과 특정 호스팅에서 실제 거래가 성공한다는 보장은 구분한다. 변경에 제품 버전 증가, 신규 배포 ZIP/태그/Release 생성, 런타임 로직·고객 데이터 구조 변경은 포함하지 않았다. 기존 Release 첨부 ZIP은 당시 배포물로 보존했다.

후속 실행 검증: [새 설치·주요 기능 검증 기록](functional-validation-20261021.md). PHP 8.2·8.4 / MySQL 8.4와 PHP 8.4 / MariaDB 12.3.3에서 확인했습니다.
