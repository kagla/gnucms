# PHP 지원 버전

**PHP 8.2 이상 지원, PHP 8.4 권장**

- 최소 지원 버전은 PHP 8.2.0입니다. PHP 7.4·8.0·8.1은 지원하지 않습니다.
- 운영 환경에는 PHP 8.4를 권장합니다. 권장 버전과 최소 지원 버전을 구분합니다.
- `composer.json`의 `php >=8.2`와 설치기 `ServerCheck::MIN_PHP = '8.2.0'`이 최소 조건입니다.
- 설치기·사이트·README·공개 매뉴얼·검색 자료의 PHP 안내는 위 문구로 통일합니다.
- CI나 과거 시험 기록의 PHP 버전은 해당 실행 환경입니다. 그 버전만 지원한다는 의미가 아닙니다.
- 초기 설계의 하위 버전 호환 제약과 예전 명령 예시는 현재 설치 조건이 아닙니다. 과거 기록은 당시 자료임을 표시하고 현재 지원 기준을 함께 안내합니다.

MySQL·MariaDB는 공통으로 `pdo_mysql` 드라이버를 사용합니다. 필요한 PHP 확장과 파일 배치는 공개 매뉴얼의 새로 설치하기 문서를 따릅니다.
