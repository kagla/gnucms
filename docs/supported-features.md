# 현재 지원 범위

2026-10-21 소스 기준입니다. 현재 운영 안내는 이 문서와 [공개 매뉴얼](https://gnucms.com/manual/support)을 따릅니다. 과거 계획·작업 기록·커뮤니티 경험담은 현재 기능 보장이 아닙니다.

| 항목 | 지원 내용과 제한 |
|---|---|
| 실행 환경 | PHP 8.2 이상 지원, PHP 8.4 권장. MySQL, MariaDB 지원. SQLite·PostgreSQL 미지원. |
| 필수·선택 확장 | PDO, pdo_mysql, mbstring, fileinfo, openssl, phar 필수. zip은 ZIP 백업, gd는 이미지 축소본용 선택 확장. sodium은 필수가 아닙니다. |
| 회원·콘텐츠 | 이메일 및 Google·네이버·카카오 로그인, 게시판·댓글·문서·첨부를 지원합니다. 소셜 로그인은 공급자 앱 설정이 필요합니다. |
| 쇼핑몰 | 코어에 포함되며 별도 모듈 설치가 필요 없습니다. 공개 여부는 상점 설정에서 끕니다. 주문·주문 조회는 로그인한 회원용이며 비회원 주문은 지원하지 않습니다. |
| 결제 | 신규 온라인 주문은 이니시스·NHN KCP 기존 TCP/IP·토스페이먼츠·나이스페이먼츠의 일반 신용카드를 지원합니다. PG 계약·키·호스팅 실행 조건을 별도로 갖춰야 합니다. 상점 무통장입금은 관리자가 실제 입금을 확인합니다. |
| 결제 제한 | KCP REST API는 신규 선택·결제를 중단하고 기존 주문 조회·환불만 유지합니다. PG 실시간 계좌이체·가상계좌·휴대폰·독립 간편결제·에스크로는 신규 주문에서 제공하지 않습니다. 토스 카드창의 등록 카드 전액 결제는 카드 결제로 취급합니다. |
| 환불·배송 | KCP 기존 TCP/IP는 전체 취소만 지원하고 PG 원격 조회 대신 GNUCMS 승인·취소 원장으로 확인합니다. 다른 지원 PG는 부분 환불을 지원합니다. 주문 전체 반품을 지원하며 상품 일부 반품·교환은 제공하지 않습니다. 배송은 운송장 등록 방식이며 택배사 자동 배송 추적을 제공하지 않습니다. |
| 메일·전화 알림 | 설정 → 알림·발송에서 미사용·서버 기본 메일·SMTP와 전화 채널 4가지 방식을 선택합니다. SMTP는 Gmail·네이버·카카오·다음·직접 입력을 지원합니다. 서버 기본 메일의 수신 성공을 보장하지 않습니다. 알리고 계정·승인된 알림톡 템플릿·발송 비용은 별도입니다. |
| 알림함 | 알림함 지원 이벤트는 필수 기록합니다. 이메일 인증과 로그인 전 비밀번호 재설정은 알림함 대상이 아닙니다. 이벤트별 메일·전화 지원 여부와 공통 발송 설정이 함께 적용됩니다. |
| 외부 서비스 코드 | 소유 확인 태그·애널리틱스·애드센스 코드 입력을 지원합니다. 내장 CMP·광고/분석 동의에 따른 자동 코드 차단은 현재 코어에서 제공하지 않습니다. 회원가입 약관 동의와 동의 기록은 유지합니다. |
| 백업·복원 | 관리 화면과 CLI는 전체 백업 생성·가져오기·검증·다운로드를 지원합니다. 자동 DB/파일 복원은 제공하지 않으며 SQL과 업로드·설정의 수동 복원이 필요합니다. mysqldump와 외부 명령 실행이 필요합니다. 자동 정기 백업·최근 5개 자동 보관·업그레이드 직전 자동 DB 백업은 제공하지 않습니다. CLI 예약은 서버에서 별도로 설정합니다. |
| 테마 | 일반 배포 코어는 선택 테마의 화면을 사용하므로 기본 테마를 복사해 필요한 화면을 갖춥니다. 정적 파일은 default 대체 경로가 있습니다. 공식 사이트의 modern 및 화면 fallback 보완은 공식 사이트 저장소의 별도 구현입니다. |
| 원격 설치 서비스 | GNUCMS.com의 별도 서비스입니다. PHP 8.2 이상·MySQL/MariaDB·HTTPS·파일 전송을 확인하고 코어와 테마를 설치합니다. 기존 CMS 데이터 이전·자동 업데이트·PG 계약/키 자동 설정을 제공하지 않습니다. 템플릿 전체의 모든 호스팅 호환성을 보장하지 않습니다. |
