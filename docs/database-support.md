# 데이터베이스 지원 정책

GNUCMS 코어·알리고·쇼핑몰은 **MySQL, MariaDB를 지원**합니다.

| 데이터베이스 | 지원 여부 |
| --- | --- |
| MySQL | 지원 |
| MariaDB | 지원 |
| SQLite | 미지원 |
| PostgreSQL | 미지원 |

MySQL과 MariaDB의 설치·운영·개발 환경은 공통으로 PHP의 `pdo_mysql` 드라이버와 `mysql:` DSN을 사용합니다.
호스팅에서 MySQL 또는 MariaDB DB와 전용 계정을 준비하고 DB 호스트·포트·이름·사용자·비밀번호를 입력합니다.
문자셋은 `utf8mb4`, 기본 포트는 `3306`입니다.

SQLite·PostgreSQL 설치, 실행, 대체 연결과 다른 DB에서의 자동 변환은 제공하지 않습니다.
백업은 MySQL/MariaDB SQL 덤프를 포함한 전체 수동 백업을 사용하고 복원은 MySQL/MariaDB 운영 절차를 따릅니다.
DB 구조 갱신 전에 운영자가 전체 백업을 확보해야 합니다.

현재 지원 범위는 README와 공개 매뉴얼의 설치·DB 개발 문서 및 검색 자료에도 동일하게 표시합니다.
이전 릴리스 변경 내역, 과거 설계·작업 계획과 테스트 기록의 SQLite 예시는 당시 이력이며 현재 지원 기능이 아닙니다.
과거 코드 예시나 실행 결과를 MySQL에서 수행한 기록으로 바꾸지 않습니다.
